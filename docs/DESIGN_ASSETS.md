# DESIGN ASSETS — generated reference images (not evidence)

Two images under `assets/design/` were produced on 2026-11-08 to settle the console layout before the real UI was written. They were generated by Codex CLI 0.165.0 (`codex exec --skip-git-repo-check -s read-only`, built-in image generation, ChatGPT login) from text-only prompts that described fictional scenes. No project data, frames, screenshots or measurements were given to the generator. Provenance for both files (generator command, source path under `~/.codex/generated_images/`, date, prompt) is archived in `assets/design/PROMPTS.json`; full prompts are stored there for both images (the empty-state prompt was copied from the Opus command text, see its `prompt_source` field).

## Rule

These images are design references only. Every number, point cloud, frame thumbnail, progress value and status in them is invented by the image model. They must never be quoted as results, pasted into reports as output, or compared with real maps. Real evidence lives only under `outputs/evidence/` (for the UI: `outputs/evidence/ui/*.png` and `ui_smoke.json`).

## 1. `assets/design/mockup_map_console_v1.png`

- **Purpose:** one-screen layout study for the map console (dark theme).
- **Generator / prompt summary:** Codex image generation; the archived prompt (`assets/design/PROMPTS.json`, first entry) asked for one 16:9 UI mockup of a "Security Drone A — Map Console" ground-control web app: calm dark slate background, no glow/neon/gradients; thin top bar with app name, input selector and status badges ("STORED_RECONSTRUCTION", "RELATIVE SCALE", "NOT NAVIGATION SAFE", "SIMULATED OFF"); large camera-frame panel with a generic office desk (fictional, no people or faces) and a scrubber; equally large 3D point-cloud viewer with a trajectory polyline and small frustums; narrow right column with Build map / cancel / collapsed settings and job steps Frames, Features, Matching, Mapping, Export; bottom monospace metrics strip (registered frames, 3D points, reprojection error, p50/p95); status colours green/amber/red/gray each with a text label; 6 px radius, 1 px borders; no real logos, people, faces or watermarks.
- **What the image shows (all fictional):** header label badges `STORED_RECONSTRUCTION`, `RELATIVE SCALE`, `NOT NAVIGATION SAFE`, `SIMULATED OFF`; "Camera frame 086/240" with a filmstrip of thumbnails; "Sparse 3D map" with an orbit control and a yellow chip "Relative units · Scale unknown"; "Map controls" (Build map / Cancel / Settings); "Job progress 68 %" with steps Frames, Features, Matching, Mapping, Export; a status strip "Registered frames 184/240 | 3D points 12,486 | Reprojection error 0.84 px | p50 142 ms | p95 318 ms". None of these values came from a run.
- **Adopted into the real console (`apps/desktop/static/`):**
  - top row of label badges driven by `map_report.json` labels (real run shows `STORED_RECONSTRUCTION`, `PUBLIC_DATASET`, `SCALE RELATIVE`, `NOT_NAVIGATION_SAFE`, `CALIB PROVIDED`, `SERVER ONLINE`; see `outputs/evidence/ui/02_real_map_loaded.png`);
  - camera | map split with a right-hand controls column (Build map, Job progress, Stored maps, Vehicle link);
  - job progress panel with step names and a Cancel button (`ui_smoke.json`: "build shows progress while running", "cancel asks for confirmation");
  - frame filmstrip under the camera pane (`index.html` `#filmstrip`, `app.css .filmstrip`);
  - monospace metrics strip in the footer (`index.html` `footer.statusbar`, `app.js renderMetrics()`), populated from the loaded report and live render timing;
  - the chip text "Relative units · scale unknown" (`app.js`, `chip("Relative units · scale unknown", "warn")`).
- **Not adopted:** the orbit camera path and frusta styling as drawn, the "Navigation safety ERROR" wording, the "Review only" footer label, and the invented numbers.

## 2. `assets/design/empty_state_mapping_flow.png`

- **Purpose:** illustration for the console's empty state (no map loaded) explaining what the pipeline does.
- **Generator / prompt summary:** Codex image generation (`assets/design/PROMPTS.json`, second entry): flat line-art, slate/cyan/amber on #171a21, three steps — phone translating past a desk, matched features across overlapping frames, sparse 3D desk with trajectory and frustums; no text/people. Resulting image: a minimal four-step diagram on a dark background: a static desk scene, a camera moving sideways (arrow), overlapping frames with matched feature points, and a resulting dotted 3D sketch with camera frusta along a path. Fictional scene, no text.
- **UI copy:** `apps/desktop/static/empty_state_mapping_flow.jpg` is a cropped 1200 px JPEG of this PNG, referenced from `index.html` with the alt text "Illustration: move a camera sideways past a static scene, frames are matched, and a sparse 3D map with camera positions is reconstructed." It appears only in the NO_INPUT state (`outputs/evidence/ui/01_empty_state.png`).
- **Adopted:** the message itself (sideways translation past a static scene -> matched frames -> sparse map), which matches the capture tips in `README.md`.
