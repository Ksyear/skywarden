# Source record: OSNet x0.25 person appearance model (ONNX, CPU, optional/opt-in)
- Architecture: OSNet (Zhou et al., "Omni-Scale Feature Learning for Person Re-Identification", ICCV 2019). Reference code: deep-person-reid, MIT License (Copyright (c) 2018 Kaiyang Zhou), file torchreid/models/osnet.py at commit f8cd150fdf77e8d9e1ed143b7f308c2c609ded50 (SHA-256 c7c1c29187d6330f859c91da229271531920464c7011aec13842a086b2263cae); downloaded at export time, not copied into this repository.
- Weights: osnet_x0_25 trained on Market-1501 from the deep-person-reid model zoo (Rank-1 91.2, mAP 75.0 as listed there), .pth SHA-256 c0ff09177a21417a19bc73bbf5af4eb5d2b097c2074ed35e67819ee6cd93612c. The model zoo states no separate license for the weights.
- Training data: Market-1501 (Zheng et al., ICCV 2015). Distributed for research use; redistribution and commercial use are not permitted by its README notice (no formal license file found, checked 2026-11-15). Treat the weights as non-commercial research use only. DukeMTMC-trained weights were deliberately not used (dataset withdrawn).
- ONNX: osnet_x0_25_market1501.onnx, SHA-256 3900a122fe9a02c1fc7a6f9cf3a4b03d61670d6527d953e34723f29188385c58, made once by scripts/export_reid_onnx.py in a separate venv (torch 2.15.0, legacy exporter, opset 17, dynamic batch). Input N x 3 x 256 x 128 RGB, ImageNet mean/std; output N x 512. OpenCV DNN output matches torch within 2.3e-6.
- Not committed (.gitignore). Runtime: OpenCV DNN CPU, local only. Embeddings are never written to disk (packages/vision/reid.py, tests/test_occlusion_tracking.py).
